# Triage labels

Canonical roles map directly to tracker labels:

| Role / label | Meaning |
| --- | --- |
| needs-triage | Maintainer evaluation needed |
| needs-info | Waiting on reporter information |
| ready-for-agent | Fully specified for autonomous agent work |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |

Use these exact strings when an engineering skill names a triage role.

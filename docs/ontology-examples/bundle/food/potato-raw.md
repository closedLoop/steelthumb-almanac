# Potatoes, flesh and skin, raw

This is USDA SR Legacy food **Potatoes, flesh and skin, raw**, FDC 170026. Values below use 100 g of the described edible food, not 100 g of the whole plant or a usual serving.[^fdc-170026]

Applies to [potato](../crops/potato.md) at generic food scope. **Do not relabel these as cultivar measurements.**

- Part: Tuber flesh and skin.
- Preparation: raw.
- Source snapshot: [USDA API record](../references/data/fdc-170026.json).
- SR Legacy is historical reference data; the retrieval date is not the laboratory measurement date.

# Per-entity OKF quality assessment

Codex working-tree review, 2026-09-27, using the [quality rubric](../../.agents/skills/build-crop-knowledge/references/RUBRIC.md). **65 concepts individually assessed; reserved index assessed separately.** Snapshot SHA-256: `01845802c88ccc5d5dcebf0872d3ca649316404a23669720f952c21e76b143d4` (sorted Markdown paths, NUL, file SHA-256, newline).

All **171 embedded claims** were compared with cited source passages in the [citation ledger](citation-fidelity.json). R3 is 3 rather than 4: prose/card review is sampled and editorial, not an exhaustive independent second review of every sentence. Scores do not establish field outcomes or formal OKF verification. The source checker checks structure and staleness, not truth. Source catalogs and editorial navigation are rated for documentary accuracy and scope, not agricultural effectiveness.

Ratings are 0–4. R: applicability, source fitness, fidelity, conflicts (weights 10/10/15/5). U: summary/card, task completion, failure handling, actionable gaps (10/15/10/5). O: structural data, navigation/maintenance (10/10). Every dimension is shown; totals should not be used to rank unlike entity types.

The bundle now stands alone. Basil procedures use direct sources; legacy assumptions and research leads are excluded. Fifteen crop/cultivar cards expose planting and harvest decisions. Named container routes address snap pea, nasturtium and dwarf sunflower; mint has a sourced container class. Sweet-potato curing now includes humidity. Citation review corrected citrus watering attribution and clarified tomato minimum container dimensions.

Remaining limitations: rockwool is a planning checklist; long-term citrus/fabric performance lacks direct evidence; sunflower food-seed drying lacks a home-scale measured endpoint. Regional settings and named packet recommendations are not universal optima. Some consequential prose remains outside embedded claims and some compound quantitative claims lack separate quantity fields. These limitations prevent treating every route as complete despite passing structural checks.

# Next ten crop research candidates

Proposed research backlog, not completed growing guidance or a recommendation for a particular climate. Include ground and grow-bag routes where evidence supports them. Start with one complete pilot using the [crop quality rubric](../../.agents/skills/build-crop-knowledge/references/RUBRIC.md).

| Plant | First research question |
| --- | --- |
| Radish | How do cultivar/root shape and harvest timing affect bag depth and usable roots? |
| Carrot | Which root lengths suit specific container depths, and what supports reliable emergence and thinning? |
| Beet | How should root and leaf harvest goals change spacing and picking guidance? |
| Leaf lettuce | What supports repeated leaf picking, and which heat/bolting cues should guide seasonal timing? |
| Spinach | How do cultivar, temperature, and day length change planting windows and bolting risk? |
| Kale | What are supported spacing, repeated-harvest, and container-care instructions? |
| Bush bean | What container volume/density and harvest cues are supported for named bush selections? |
| Cucumber | Which compact or vining selections have documented container, support, and pollination requirements? |
| Zucchini | What bag dimensions, moisture management, and fruit-set checks are supported? |
| Strawberry | How do bearing type, crown planting, and container overwintering change the growing procedure? |

For each candidate, inspect a relevant growing guide and identity source first, then target the unresolved decision. No bag size, maturity interval, yield, or climate suitability is asserted by inclusion here.

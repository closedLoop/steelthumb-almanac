# Choose a basil selection

Start with the [basil](../crops/basil.md) or [sweet-basil](../crops/sweet-basil.md) profile, then preserve the exact selection and supplier label. Flavor groups and cultivar names serve different purposes.

## Selection checks

- For limited space, UF/IFAS identifies Spicy Globe and Dwarf Greek basil as compact container choices.[^uf-basil]
- For disease pressure, name the disease. Clemson lists Nufar as Fusarium-resistant, while Minnesota lists it as highly susceptible to downy mildew.[^clemson-basil][^umn-downy]
- For downy-mildew resistance in a container selection, Minnesota lists Prospera Compact DMR.[^umn-downy] Resistance is not immunity or a guarantee of local performance.

Clemson describes Pesto Perpetuo as nonflowering.[^clemson-basil] Do not infer that all perennial or vegetatively propagated basils are nonflowering. Check the identified selection before planning [seed saving](../procedures/save-basil-seed.md).

## Applicability and follow-up

Record identity separately from supplier, lot and observed traits. If the botanical name is ambiguous, obtain a botanical or breeder record before creating a species or hybrid profile. No height, flavor or resistance value is inherited automatically by an unspecified basil.

UF/IFAS's blanket statement that all sweet varieties are downy-mildew susceptible conflicts with named resistant selections in Minnesota's disease guide. Use the disease-specific named evidence rather than that blanket statement. See [symptom investigation](../procedures/investigate-basil-symptoms.md).

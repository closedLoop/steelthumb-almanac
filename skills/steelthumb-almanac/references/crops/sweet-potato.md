# Sweet potatoes

<a id="identity"></a>
Sweet potato, Ipomoea batatas, produces storage roots and is distinct from true yams.[^umd-sweet]

Ipomoea batatas for storage roots in warm-season beds or outdoor grow bags; cultivar unspecified.

## Quick reference

Seed-packet-style summary; linked claims retain the source and growing conditions.

| Field | Guidance |
| --- | --- |
| Start with | Labelled sweet-potato slips with healthy roots; cultivar should fit the available warm season. |
| When to plant | [After frost risk passes; soil reaches 65°F](../procedures/plant-sweet-potato.md#warm-soil) (Maryland). |
| Depth | [2–3 in deep](../procedures/plant-sweet-potato.md#slip-depth) (Alabama guidance). |
| Ground spacing | [12 in within rows](../procedures/plant-sweet-potato.md#slip-spacing); [40 in between rows](../procedures/plant-sweet-potato.md#row-spacing) (Maryland). |
| Light | [Full sun](../procedures/plant-sweet-potato.md#site-light). |
| Establishment / maturity | Water while slips establish; local days to harvest require cultivar guidance. Use usable root size and the frost deadline below. |
| Water | [Moisture during establishment and growth; avoid saturation](../procedures/care-for-sweet-potato.md#water). |
| Harvest | [Eating-size roots before frost; handle without washing; handle gently](../procedures/harvest-sweet-potato.md#before-frost). |
| Curing / storage | [Complete Mississippi temperature, humidity and duration route](../procedures/harvest-sweet-potato.md#cure-msu); [storage conditions](../procedures/harvest-sweet-potato.md#storage-msu). |
| Grow bag | [One plant per nominal 10-gallon container, including fabric](../procedures/plant-sweet-potato.md#bag-size) (Maryland recommendation, not a volume trial). |

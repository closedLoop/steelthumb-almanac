# Jalapeño peppers

<a id="identity"></a>
Jalapeño peppers belong to Capsicum annuum.[^uconn-pepper]

Jalapeño-type Capsicum annuum for fruit; warm-season beds and outdoor grow bags, cultivar unspecified.

## Quick reference

Seed-packet-style summary; linked claims retain the source and growing conditions.

| Field | Guidance |
| --- | --- |
| Start with | Labelled, hardened jalapeño transplants; seed-starting is a separate task. |
| When to plant | [Night lows stay above 50°F](../procedures/plant-jalapeno-pepper.md#night-temperature) (Minnesota) and [soil reaches 65°F](../procedures/plant-jalapeno-pepper.md#soil-temperature) (Maryland); different measurements. |
| Depth | [Previous soil line; water in](../procedures/plant-jalapeno-pepper.md#depth). |
| Ground spacing | [18 in between plants](../procedures/plant-jalapeno-pepper.md#spacing); [30–36 in between rows](../procedures/plant-jalapeno-pepper.md#row-spacing). |
| Light / support | [Full sun](../procedures/plant-jalapeno-pepper.md#site-light); [use cages or short trellises](../procedures/care-for-jalapeno-pepper.md#support). |
| Emergence / maturity | Seed emergence is outside this route. Obtain the cultivar’s transplant-to-harvest estimate; use fruit readiness below. |
| Water | [Maintain even root-zone moisture](../procedures/care-for-jalapeno-pepper.md#water). |
| Harvest | [Mature-sized green fruit; clip stems](../procedures/harvest-jalapeno-pepper.md#green-harvest); [wear gloves and wash hands](../procedures/harvest-jalapeno-pepper.md#handling). |
| Grow bag | [Pepper-specific minimum: 5 gallons](../procedures/plant-jalapeno-pepper.md#bag-size) (Maryland). One plant is the procedure’s editorial density choice; fabric performance and optimum remain unestablished. |


Full instructions: [plant](../procedures/plant-jalapeno-pepper.md), [care and investigate](../procedures/care-for-jalapeno-pepper.md), [harvest](../procedures/harvest-jalapeno-pepper.md), and [grow-bag setup](../systems/outdoor-grow-bags.md).

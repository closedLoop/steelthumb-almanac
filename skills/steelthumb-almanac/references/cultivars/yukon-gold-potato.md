# Yukon Gold potato

<a id="early-yellow"></a>
Iowa State describes Yukon Gold as an early-season, yellow-fleshed potato cultivar.[^isu-potato]

Named Yukon Gold cultivar; “Yukon potatoes” is interpreted as Yukon Gold pending an actual planting label.
